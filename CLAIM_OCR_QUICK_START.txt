🎯 N8N WORKFLOW NODES (Quick Reference)
───────────────────────────────────────────────────────────────────────────────

Node 1: Webhook
  Type: Webhook
  Method: POST
  Path: cgpe-claim-webhook

Node 2: If (Has Document?)
  Condition: $json.message.type == 'document'

Node 3: Extract URL
  Function: Return document URL from payload

Node 4: HTTP Download
  Method: GET
  URL: from Node 3
  Return: Binary

Node 5: Convert Base64
  Function: Buffer.from().toString('base64')

Node 6: Call Express API
  Method: POST
  URL: http://localhost:3000/api/claim/analyze
  Body: base64PDF + metadata

Node 7: Format Customer Response
  Format analysis for readability

Node 8: Send WhatsApp
  Customer + Admin messages
