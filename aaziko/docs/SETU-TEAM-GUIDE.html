3. Ek SUPPLIER mail (jaise Vinipul)

  1. "Let Setu handle" → supplier-reply draft (terms maangega). Review panel khulega.
  2. "💬 View thread" → 📎 COA specs table apne aap (scanned bhi OCR se).
  3. 🔍 Spec match me seedha 🔗 Auto-match → CONFORM ya DEVIATION (bina paste).
  4. 💰 CIF calc: QTY/buyer auto-filled. Aap sirf Markup / Forwarding / Ocean Freight daalo → Calculate → ₹ & $.
  5. 📧 Draft quotation → buyer ko CIF quote (numbers Setu compute, verified).
  6. Review → Approve → ✓ Send (gated).

4. Ek BUYER mail

  1. "Let Setu handle" → buyer-style reply draft.
  2. Buyer ne spec diya → Setu requirement save kar leta (aage supplier COA auto-match hoga).
  3. Review → Approve → (gated) Send.

Manually save: thread me "📋 Save this thread as a buyer requirement".

6. Bharosa kyun (safety)

  • Supplier vs Buyer sahi — supplier ko landed-quote nahi deta.
  • SHADOW — bina approve kuch nahi; send sirf allowlist.
